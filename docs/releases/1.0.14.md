# 高糖小食 1.0.14

## 本次更新

- 修正底栏玻璃「透明到看不见」的问题：
  - 上一版把玻璃底色设为纯白 12% 不透明度，在奶油色浅色页面上几乎完全隐形。
  - 现改为暖奶油色 `#FFF7F2` 38% 不透明度，与「高糖小食」配色一致，玻璃面板清晰可读。
  - 边缘高光由 0.5dp 加宽到 1dp，轮廓更明确。
- 按系统能力分级兜底：Android 13+ 折射 + 模糊；Android 12 模糊；Android 11 及以下半透明底。
- 说明：液态玻璃的**折射**在背后有照片、花纹或文字边缘时才明显；纯色平坦页面只能看到模糊与高光，属正常物理表现。

## 安装说明

下载 `1.0.14.apk`，在 Android 7.0 或更高版本设备上安装。同签名覆盖安装会保留本地数据。
