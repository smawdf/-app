# 高糖小食 · Flutter 新版（内测包）

> ⚠️ **这是独立的新版App，与现有正式版并存安装，互不覆盖。**
> 应用名显示为「高糖小食·新版」，包名 `com.myorderapp.orderdisk_flutter`。
> 因为它是 **Pre-release**，现有正式版的 App 内更新不会检测到它，请放心。

## 一、这版是什么

用 **Flutter 重写的前端** + **Go 全新后端**，替换原先的 Kotlin/Compose + Supabase 架构。

| 层 | 技术栈 |
| :--- | :--- |
| 前端 | Flutter 3.47（Impeller 渲染） |
| 后端 | Go 1.27 + Gin + GORM + SQLite + WebSocket |
| 视觉 | 纯白底色 + 悬浮水滴液态玻璃底栏 |

## 二、实测已验证的能力

- ✅ 注册 / 登录（JWT，bcrypt 加密）
- ✅ 情侣 6 位邀请码配对，配对后自动预置 6 道招牌菜
- ✅ 点菜、加购、下单，**事务级扣减糖币**
- ✅ 订单状态机：待接单 → 已接单 → 烹饪中 → 端盘 → 开饭
- ✅ **糖币不足自动拦截**
- ✅ 糖币流水账本
- ✅ **WebSocket 实时推送**：对方撒糖 / 点菜 / 改状态，本机毫秒级收到并刷新
- ✅ **登录态持久化**：杀掉 App 重启，免登录直接进入

## 三、真机安装与联调步骤（重要）

这版前端连的是**你自己电脑上运行的 Go 后端**，所以手机必须和电脑在**同一个 WiFi**。

1. **在电脑上启动后端**：
   ```powershell
   cd D:\kaifa\myapp\orderdisk-server
   .\orderdisk-server.exe
   ```
   看到 `Listening and serving HTTP on :8085` 即成功。

2. **查电脑的局域网 IP**：
   ```powershell
   ipconfig
   ```
   找 `IPv4 地址`，例如 `192.168.1.6`。

3. **手机安装本 APK**，打开后**先点登录页最下方的「服务器 … 修改」**，
   填成你电脑的 IP（默认已填 `192.168.1.6`），点「保存并测试」。
   显示「连接正常 ✅」即可。

4. **登录测试**：
   - 点「吃货 小马」→ 自动填入账号 `eat2` / 密码 `123` → 点登录
   - 或点「饲养员 小金毛」→ 账号 `cook2` / 密码 `123`

   > 这两个演示账号建立在开发机上，如果你想用自己的账号，
   > 切到「注册」页新建即可（第一次用需要一方生成邀请码、另一方输入绑定）。

## 四、已知限制

1. **必须连同一个 WiFi**，且电脑防火墙需放行 8085 端口；出门在外无法使用。
2. **菜品图片目前是 emoji 占位符**，真实图床还未接入。
3. 后端数据库是本地 SQLite 文件，**换电脑需要重新注册账号**。
4. Release 包体积 51.6 MB（未开 R8 混淆，优先保证稳定性）。

## 五、安装说明

下载 `orderdisk-flutter-2.0.0.apk`，在 Android 7.0+ 设备上安装。
与现有「高糖小食」正式版**互不冲突**，可同时安装对比。
