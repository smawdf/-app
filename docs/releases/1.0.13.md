# 高糖小食 1.0.13

## 本次更新

- 底栏改用**真实「液态玻璃」折射渲染**，替换 1.0.12 的纯模糊方案：
  - 接入基于圆角矩形距离场（SDF）的像素折射，玻璃边缘产生真实的透镜弯曲位移，而不是单纯磨砂模糊。
  - 开启棱镜色散（chromatic aberration），边缘出现极轻微的红蓝分光。
  - 改用图形库内置高光渲染，替换自绘描边，修掉上一版边框与高光重叠产生的「双重边缘」。
- 兼容性说明：折射需要 **Android 13（API 33）及以上**才会渲染；Android 12 自动降级为背景模糊；Android 11 及以下降级为浅色半透明底。

## 安装说明

下载 `1.0.13.apk`，在 Android 7.0 或更高版本设备上安装。同签名覆盖安装会保留本地数据。
