# 高糖小食更新日志

## 1.0.13

- 底栏改用真实液态玻璃折射渲染（SDF 折射 + 棱镜色散 + 内置高光），替换 1.0.12 的纯模糊方案。
- 修掉边框与自绘高光重叠导致的双重边缘。
- 折射需 Android 13+；Android 12 降级为模糊，Android 11 及以下降级为半透明底。

## 1.0.12

- 全面接入底层背景实时采样与硬件级毛玻璃（Haze 引擎）。
- 滑动菜品列表时，背后的菜品照片和文字会被 GPU 硬件进行实时的 24.dp 高斯模糊与高透透光。
- 叠加 1.5px 纯白切角钻石反光刃与凸面月牙水光，呈现真实立体的液态玻璃悬浮质感。

## 1.0.11

- 全新升级「真·纯清水滴透明液态玻璃」悬浮底栏，彻底剔除发灰发白的磨砂雾感。
- 采用超高透纯清水基底，滑动菜品与文字完全清晰透过底栏。
- 引入顶部 1.5px 极亮纯白钻石切角反光刃与凸面月牙水光反射，赋予底栏如纯净水滴凝聚般的立体光泽。
- 接入 Kyant 核心图形库，优化流体边缘与高光质感。

## 1.0.10

- 修复部分历史订单因云端用户字段为空而无法解码，导致订单同步失败。
- 修复订单或明细只上传了一部分后，重复同步被云端权限规则拒绝的问题。
- 重试时只补传云端缺失的订单和明细，保留本地订单并自动恢复同步。

## 1.0.9

- 修复 App 更新或重启后，本地登录状态已恢复但云端认证尚未就绪时出现的数据同步失败。
- 网络异常或云端会话暂时不可用时保留本地登录和本地数据，不再强制退出账号。
- 情侣绑定或解绑后自动切换菜单数据范围，绑定成功后立即重新同步双方资料和共享数据。

## 1.0.8

- 修复今日推荐和减脂推荐可能显示同一道菜的问题。
- 推荐候选会排除已经加入“我的店铺”的菜品。
- 菜单同步或加入菜品后，推荐会自动重新计算；减脂候选不足时使用其他未加入店铺的菜品补位。

## 1.0.7

- 登录后自动检查更新，发现新版本时支持取消或立即更新。
- 每日推荐改为按日期稳定随机，并避免与减脂推荐重复。

## 1.0.3 (36) - 2026-07-16

图片显示策略修复。

- 点菜详情和发现详情继续完整展示原图，不拉伸图片。
